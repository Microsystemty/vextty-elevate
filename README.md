# VEXTTY Elevate

Crie o site institucional responsivo da VEXTTY — Sistemas & Tecnologia, empresa de sistemas, SaaS, sites e soluções digitais para diversos segmentos.

Visual premium, corporativo e tecnológico, com azul elétrico, branco e fundo azul quase preto, gradientes e animações suaves.

Crie uma Home básica com header, Hero impactante, soluções, apresentação da empresa, CTA e footer. Use componentes reutilizáveis e código bem organizado.

Não configure banco de dados, Supabase, login ou backend. Apenas frontend.

Tecnologia que transforma ideias em resultados.
